# Çıktı Klasörü

Bu klasör, analiz sonuçlarınızı içerir:

- **Grafikler**: `.png` formatında yüksek çözünürlüklü grafikler
- **PDF Raporlar**: Detaylı analiz raporları
- **Karşılaştırma Grafikleri**: Test karşılaştırma sonuçları

## Oluşturulan Dosyalar

### Grafikler
- `speed_profile.png` - Hız profili
- `power_profile.png` - Güç profili
- `energy_consumption.png` - Enerji tüketimi
- `soc_profile_<kapasite>kwh.png` - SOC değişimi
- `temperature_effect.png` - Sıcaklık etkisi
- `phase_distribution.png` - Faz dağılımı
- `range_comparison.png` - Menzil karşılaştırması

### Karşılaştırma
- `comparison_consumption.png` - Tüketim karşılaştırması
- `comparison_performance.png` - Performans karşılaştırması
- `comparison_speed_profiles.png` - Hız profilleri

### PDF Raporlar
- `enerji_raporu_<tarih_saat>.pdf` - Analiz raporu

## Not

Bu klasördeki dosyalar `.gitignore` ile versiyon kontrolünden hariç tutulmuştur.
